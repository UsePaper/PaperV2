# On writing in plain text

I have kept my notes in plain text for eleven years. Here is why that has not changed.

## It outlives the tool

The first note I still have was written in an editor that no longer exists. It opens today because it is only text, and text is the one format every tool agrees on.

Compare that with the documents I wrote in the same decade in a word processor. Half of them open with the wrong fonts. A few do not open at all.

## It is fast

There is no loading spinner on a text file. There is no sync conflict, no account, and no upgrade prompt.

> The best tool is the one that gets out of the way.

## It is searchable

Every operating system can search plain text, and so can `grep`. My notes are one folder and one command away, always.

## What I gave up

- Pictures, mostly
- Comments from other people
- Anything that needs a page count

I think that is a fair trade. See [the setup I use](https://example.com/setup) if you want the details.
