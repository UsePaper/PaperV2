# Glossary

**Block** — a paragraph, a heading, a list, a quote or a fence. Blocks stack down the page.

**Inline** — anything inside a block: text, emphasis, code, links and images.

**Mark** — the formatting carried by a run of text, such as *emphasis* or `code`. A mark is not a block.

**Round trip** — parsing text into a document and writing it back out. The result must match what went in.

**Canonical form** — the one spelling of a document that the serializer produces. See `tests/roundtrip`.
