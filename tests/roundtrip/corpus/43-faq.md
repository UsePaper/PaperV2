# Questions people ask

## Does it work offline?

Yes. Nothing here talks to the network.

## Where are my settings kept?

In one file, in the usual place for your system. Delete it to start over.

## Can I open two documents at once?

Open a second window. Each window holds one file, its own history and its own unsaved marker.

## Why is there no preview pane?

Because the text on screen is already the formatted result. A preview would be a second copy of the same thing.

## Can I get the raw Markdown back?

Yes, with the source view. It shows the file exactly as it sits on disk.
