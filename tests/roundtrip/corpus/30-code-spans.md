A code span holding a backtick: `` a`b ``.

A code span holding two: ``` a``b ```.

A code span holding markup that must stay literal: `**not strong**`.

A code span holding an underscore pair: `_not emphasis_`.

A code span next to **strong text**: `code` and more.

A bare pair of backticks is text, and is written back escaped: \`\`.
